# Stage 16: IRS 2025 Tax Table first panel

Source: https://www.irs.gov/publications/p1040 (2025 Tax Table)

Transcribed all 42 income intervals in the official first panel, from $0 to less than $1,000, for all four filing statuses. Retained the four IRS example rows from $25,200 to less than $25,400. Qualifying surviving spouse uses married-filing-jointly column. Other values below $100,000 are deliberately blocked rather than estimated.

This is not a complete tax table and does not establish filing readiness. Verify the official IRS source and run all tests before production deployment. The old function name lookupVerified2025SampleTax is retained for compatibility, though it now covers the first panel as well.
