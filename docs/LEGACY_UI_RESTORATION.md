# NextGen 2.0 — legacy-style workspace restoration

This package restores a tax-workspace-first visual hierarchy using the existing standalone React/Vite app. It preserves all existing 2025 tax logic and routes; it does NOT claim full compatibility with original Material UI / Redux legacy components.

- More compact blue/white classic tax software styling and navigation shortcuts.
- Functional return dashboard, linked to About you, Income, Deductions, Review.
- Developer reports collapsed into optional Developer tools instead of dominating every screen.
- Existing W-2, 1099-INT, eligibility questions, source audit, and 1040 review retained.
- Filing remains disabled; use fictional data only.

The supplied React component is based on the latest Consolidated Readiness 2025 snapshot. Back up the existing file before replacing it; check local build and inspect the site.
