# Phase 37 — Form 1040 workspace

Replaces the former short source ledger with a full, grouped, searchable 2025 Form 1040 line browser. Includes line filters, status labels, source navigation, and source-only dollar amounts for validated fictional W-2 and 1099-INT records. All other lines explicitly remain unresolved. Does not compute tax, claim eligibility, create PDFs or enable filing.

Install: unzip into the repository root and run `bash INSTALL_PHASE37.command`. The installer checks the existing repository, TypeScript, Vite, and architecture before committing or pushing.
