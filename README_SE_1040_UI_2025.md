# USTaxes NextGen — 2025 cross-form reconciliation UI

Adds a collapsible Schedule C/SE -> Schedule 1/2 -> Form 1040 arithmetic audit workpaper in the 2025 federal return screen. Supports manual values, candidate Form 1040 line copying, explicit review, blockers, trace and CSV export. All edits reset confirmations. No automatic posting, no filing, no taxpayer identity collection. Negative business profits and special tax methods are not supported.

This is **not** the official IRS Tax Table and does not make a return filing-ready. Local checks verify integration and build, not tax correctness. The installer commits only files in this package, checks for clean Git state, and pushes only after passing all checks.
