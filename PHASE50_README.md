# Phase 50 — Fictional Draft Persistence & Portability

Adds explicit localStorage persistence, tax-year isolation, validated JSON import/export, CSV export, cross-tab change notices, versioned schema, and eight regression fixtures to the Phase 49 field-review workspace.

**Scope:** This phase does NOT edit underlying W-2, 1099, schedules, Form 1040 or calculations. It does not enable tax filing. Use fictional data only; localStorage is not encrypted and is not suitable for real taxpayer information.

## Installation
Run `bash INSTALL_PHASE50.command` from the repository root after unzipping. Installer builds and commits only phase 50 files. If there are TypeScript errors, no commit is made.
